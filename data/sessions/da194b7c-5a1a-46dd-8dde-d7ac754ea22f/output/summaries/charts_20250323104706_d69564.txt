**Purpose**: This file is used to generate interactive line charts for stock market analysis.

**Key Components**: 
- The main function `create_interactive_chart()` which takes in data, x and y column names, and a title.
- A dependency on the `plotly.express` library, specifically its `px.line` function.

**Data Flow**: This file processes financial data by creating an interactive line chart where the date is represented on the x-axis and stock prices are plotted against time.

**Dependencies**: 
- External: `plotly.express`
- Internal: None

**Interactions**: 
- Communicates with external APIs or databases for financial data, which is then passed to this file.
- Returns an interactive chart object displayed directly in a web browser.
