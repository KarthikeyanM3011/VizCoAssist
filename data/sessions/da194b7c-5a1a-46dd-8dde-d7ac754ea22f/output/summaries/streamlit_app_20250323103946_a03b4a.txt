**Purpose**: The main goal of this file is to create a user interface for a stock market analysis application using the Streamlit framework.

**Key Components**: 
- Streamlit app with configuration and layout settings.
- Date input fields for start and end dates.
- Selectbox menu for choosing between analysis and SQL query options.
- Buttons for fetching data and executing queries.
- Functions for performing advanced analysis and executing SQL queries on loaded data.

**Data Flow**: The application loads data based on user-input start and end dates. If data is successfully fetched, it is stored in session state and can be used by subsequent functions.

**Dependencies**: 
- Streamlit framework.
- Internal modules 'analysis', 'sql_query', and 'utils'.
- External SQL database (not explicitly shown in this file).

**Interactions**: This file communicates with other parts of the system through its internal modules, which interact with external libraries or APIs to perform analysis and execute queries on loaded data.
