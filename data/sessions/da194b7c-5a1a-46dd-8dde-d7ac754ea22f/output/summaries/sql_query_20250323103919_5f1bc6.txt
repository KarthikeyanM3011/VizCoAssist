**Purpose**: The main goal of this file is to execute SQL queries on a SparkSession and display the results in a Streamlit application.

**Key Components**: 
- An `execute_sql_query` function that takes data as input, creates a SparkSession, executes an SQL query, and displays the results.
- A Streamlit interface that allows users to enter their own SQL query and view the results.

**Data Flow**: The file processes user-input data by creating a DataFrame, executing an SQL query on it, and displaying the results in a pandas DataFrame format within the Streamlit application.

**Dependencies**: 
- pyspark
- streamlit
- spark

**Interactions**: This file communicates with other parts of the system through the Streamlit interface, which allows users to interactively enter and execute SQL queries.
